# KEIBIDROP Unraid templates

The Unraid Community Applications template for the KEIBIDROP serving peer. Your Unraid box serves a folder, and your computer opens it over the internet with the KEIBIDROP desktop app, each file streamed when an application opens it and end-to-end encrypted.

- Template: [templates/keibidrop.xml](templates/keibidrop.xml)
- Image: `ghcr.io/keibisoft/keibidrop`, also on Docker Hub as `keibisoft/keibidrop`, for linux/amd64 and linux/arm64
- Setup guide: https://keibidrop.com/docs/how-to/run-on-a-nas.html
- KEIBIDROP source code and issues: https://github.com/KeibiSoft/KeibiDrop
